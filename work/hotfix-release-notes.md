Первый релиз EX-twins. Minecraft 1.21.1, Java 21, NeoForge 21.1.252+. Нужны Curios 9.5.1, Photon 2.2.7, LDLib2 2.2.41, KilaGraph (Relics не нужен).

## Что внутри

- Три автономных щита (RF, Mana, Ex-Twins): соты, бегущая волна, преломление, ответный удар по мобам, встроенные батареи, настраиваемые списки урона и снарядов.
- Три улья-роя: капля, обстрел, сдерживание, лекари; уровни, очки улучшений и модули; консоль устройства (клавиша H).
- Армагеддоны: чёрная дыра Ex-Twins, Мана-вихрь, RF-шар с куполом и кратером.
- Корабельные ульи для Create Aeronautics: «Копьё» (турель), «Эгида» (щит корпуса), «Эскорт» (крылья).
- Динамический свет эффектов при установленном LambDynamicLights.
- Русская и английская локализации, README на русском с превью из игры.

## Проверка

Все обязательные GameTests пройдены, сборка зелёная. Ставить на клиент и на сервер; перед обновлением сделайте копию мира.



Также: отталкивание и настройка щитов, фигуры роя, динамический свет эффектов (LambDynamicLights), NeoForge 21.1.251+.
