# Журнал проверок моделей

## 02.10.2026 — лимит вывода проверки сохранения Ex-Twins

`git show` для крупного OBJ превысил стандартный буфер `child_process.execFileSync` (1 MiB), вызвав ENOBUFS до сравнения. Лог `work/test-runs/2026-10-02-twins-preserve-01.log`. Исправление: явный maxBuffer 32 MiB. Повторный результат — OBJ побайтово совпадает с HEAD, изменены только цвета MTL (`2026-10-02-twins-preserve-02.log`). Не интерпретировать ошибку инфраструктуры сравнения как изменение геометрии.

## 02.10.2026 — WinRT не декодировал видео-референс

Первый запуск инструмента кадров заблокирован ExecutionPolicy; процессный запуск затем не получил StorageFile через WinRT, и зависимые API выбрасывали Invalid pointer. Ошибки воспроизвелись с ASCII-путём; журнал `work/test-runs/2026-10-02-video-ref-03.log`. Точная причина отказа WinRT не установлена. Скрипт продолжил исполнение и вернул 0, создав пустой лист — такой результат не подтверждает чтение видео. Исправление рабочего процесса: временный imageio-ffmpeg на D:, FFmpeg прочитал видео и создал действительные кадры (`2026-10-02-video-ref-04.log`). Проверен сам лист; в видео парящее ядро с отдельными сегментами, а не башня UEF. Повторный вывод FFmpeg содержит предупреждение об одиночном PNG без шаблона; кадр записан и просмотрен успешно.

## 02.10.2026 — RF обрезался в угловом программном превью

Визуальная проверка `rf_ship_shield_generator-branch-style.png` выявила обрезанные раскрытые антенны. Причина: масштаб кадра определялся максимальным размером мирового AABB; диагональная проекция шире него. Исправление: вычислять границы каждой позированной модели в плоскости камеры, центрировать их и добавлять 12% поля. Повторный рендер показывает все антенны. Отдельная запись сбоя: `work/test-runs/2026-10-02-rf-preview-crop-01.log`. Вывод: для превью подгонять камеру по проецированным вершинам, а не размерам мирового AABB.
