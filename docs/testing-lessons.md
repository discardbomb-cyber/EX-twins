## 02.10.2026 — RF обрезался в угловом программном превью

Визуальная проверка `rf_ship_shield_generator-branch-style.png` выявила обрезанные раскрытые антенны. Исправление: вычислять границы каждой позированной модели в плоскости камеры, центрировать их и добавлять 12% поля. Повторный рендер показывает все антенны. Отдельная запись сбоя: `work/test-runs/2026-10-02-rf-preview-crop-01.log`. Вывод: для превью подгонять камеру по проецированным вершинам, а не размерам мирового AABB.
