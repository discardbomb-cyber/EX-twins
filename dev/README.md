# Перенос разработки EX-twins — 03.10.2026

Резервные ветки `codex/dev-20261003/*` сохраняют локальные ветки, исходники, незавершённые изменения, модели и Markdown. Слияний и выпуска релиза при переносе нет. Основной снимок текущей рабочей папки: `codex/dev-20261003/docs/readme-ru`.

На новом ПК:

```powershell
git clone https://github.com/discardbomb-cyber/EX-twins.git
cd EX-twins
git switch --track origin/codex/dev-20261003/docs/readme-ru
```

Для релизной базы используйте резервную ветку `codex/dev-20261003/main`. Другие наработки перечислены в [списке снимков](worktree-snapshots.md). Все локальные ветки сохранены под тем же префиксом, даже если для них нет рабочей копии.

Начните с [AGENTS.md](../AGENTS.md), [карты проекта](../docs/project-map.md) и [технических правил](../docs/development.md). Исторические абсолютные пути относятся к старому ПК. Нужны JDK 21 и зависимости из build.gradle; целевая NeoForge — 21.1.251. Сохранение старых веток не исправляет их версии и не подтверждает работоспособность.

Markdown из игнорируемого `work/` сохранён принудительно; после клонирования он присутствует в Git. Архивы чатов, секреты и локальные настройки, вложенные checkout, сборочные кэши, run-каталоги, миры, внешние JAR и тяжёлые захваты не включены. Их при необходимости переносите отдельно со старого ПК, включая D:/ex-twins-captures.

Корабельные щиты исключены из релиза; копьё и коса отменены. Их резервные ветки — архив, а не разрешение возвращать функции. Код в снимках не изменялся и для переноса не пересобирался.
